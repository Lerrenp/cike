# 「此刻」图文分享社区‑MySQL数据库设计文档
文档版本：V1.0
配套产品：此刻图文分享社区（Vue3 + SpringBoot）
数据库：MySQL 8.0
字符集：`utf8mb4`（完整支持emoji表情）
排序规则：`utf8mb4_unicode_ci`

> 说明：V1.0实现核心业务：用户、笔记、笔记图片、评论、点赞、收藏、话题、草稿；适配首页瀑布流、发布、详情、个人中心、登录注册；支持三端，后端接口复用同一套数据库。
> 主键统一使用 `BIGINT` 自增；逻辑删除采用 `is_deleted`，不物理删除数据；时间字段统一 `create_time / update_time`。

## 数据库总览
|表名|中文名称|说明|
|---|---|---|
|`t_user`|用户表|账号、个人资料|
|`t_note`|笔记表|图文笔记主体|
|`t_note_image`|笔记图片表|一篇笔记多张图片，一对多|
|`t_topic`|话题表|笔记话题标签|
|`t_note_topic`|笔记话题关联表|笔记与话题多对多|
|`t_comment`|评论表|笔记评论、子回复|
|`t_user_like_note`|笔记点赞表|用户‑笔记点赞关系|
|`t_user_collect_note`|笔记收藏表|用户‑笔记收藏关系|
|`t_draft`|草稿表|用户发布页未提交草稿|

## 建表SQL

### 1. t_user 用户表
```sql
CREATE TABLE `t_user` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '用户主键ID',
  `phone` VARCHAR(11) NOT NULL COMMENT '手机号',
  `password` VARCHAR(100) NOT NULL COMMENT '加密密码',
  `nickname` VARCHAR(50) NOT NULL COMMENT '昵称',
  `avatar` VARCHAR(255) DEFAULT '' COMMENT '头像图片url',
  `bio` VARCHAR(200) DEFAULT '' COMMENT '个人简介',
  `note_count` INT DEFAULT 0 COMMENT '发布笔记数',
  `like_total` INT DEFAULT 0 COMMENT '获赞总数',
  `is_deleted` TINYINT DEFAULT 0 COMMENT '逻辑删除 0未删 1已删',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_phone` (`phone`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 2. t_note 笔记表
```sql
CREATE TABLE `t_note` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '笔记ID',
  `user_id` BIGINT NOT NULL COMMENT '发布者用户id',
  `title` VARCHAR(100) NOT NULL COMMENT '笔记标题',
  `content` TEXT NOT NULL COMMENT '笔记正文',
  `cover_url` VARCHAR(255) DEFAULT '' COMMENT '封面图（取第一张图片）',
  `view_count` INT DEFAULT 0 COMMENT '浏览量',
  `like_count` INT DEFAULT 0 COMMENT '点赞数',
  `collect_count` INT DEFAULT 0 COMMENT '收藏数',
  `comment_count` INT DEFAULT 0 COMMENT '评论数',
  `visible` TINYINT DEFAULT 1 COMMENT '可见性：1公开，2仅自己可见',
  `status` TINYINT DEFAULT 1 COMMENT '状态：1正常，0审核中，-1违规下架',
  `is_deleted` TINYINT DEFAULT 0 COMMENT '逻辑删除 0未删 1已删',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '发布时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='笔记主表';
```

### 3. t_note_image 笔记图片表（一对多）
> 一篇笔记可以上传最多9张图片，记录图片url、排序序号
```sql
CREATE TABLE `t_note_image` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `note_id` BIGINT NOT NULL COMMENT '笔记id',
  `image_url` VARCHAR(255) NOT NULL COMMENT '图片访问地址',
  `sort` INT DEFAULT 0 COMMENT '图片排序序号，越小越靠前',
  `is_deleted` TINYINT DEFAULT 0,
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_note_id` (`note_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='笔记图片表';
```

```sql
  `id` BIGINT NOT NULL AUTO_INCREMENT,
```

### 6. t_comment 评论表（支持二级回复）
```sql
CREATE TABLE `t_comment` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '评论id',
  `note_id` BIGINT NOT NULL COMMENT '所属笔记id',
  `user_id` BIGINT NOT NULL COMMENT '评论用户id',
  `parent_id` BIGINT DEFAULT 0 COMMENT '父评论id，0代表一级评论，非0为回复某条评论',
  `reply_user_id` BIGINT DEFAULT 0 COMMENT '回复目标用户id，用于子回复',
  `content` VARCHAR(500) NOT NULL COMMENT '评论内容',
  `is_deleted` TINYINT DEFAULT 0 COMMENT '逻辑删除',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_note_id` (`note_id`),
  KEY `idx_parent_id` (`parent_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评论表';
```

### 7. t_user_like_note 用户点赞笔记表
> 防止重复点赞，建立唯一联合索引；不要直接在业务表存点赞状态

```sql
CREATE TABLE `t_user_like_note` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,

  `note_id` BIGINT NOT NULL,
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_note` (`user_id`,`note_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='笔记点赞记录表';
```

### 8. t_user_collect_note 用户收藏笔记表
```sql
CREATE TABLE `t_user_collect_note` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT NOT NULL,
  `note_id` BIGINT NOT NULL,
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
```

### 9. t_draft 用户草稿表
> 发布页退出保存草稿，再次进入发布页读取；一篇用户最多保留一条草稿即可
```sql
CREATE TABLE `t_draft` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT NOT NULL COMMENT '所属用户',
  `title` VARCHAR(100) DEFAULT '' COMMENT '草稿标题',
  `content` TEXT DEFAULT '' COMMENT '草稿正文',
  `image_json` TEXT DEFAULT '' COMMENT '草稿图片列表json数组',
  `topic_ids` VARCHAR(255) DEFAULT '' COMMENT '话题id逗号分隔',
  `visible` TINYINT DEFAULT 1 COMMENT '可见设置',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='发布页草稿表';
```

## 核心业务说明 & 索引设计说明
### 1. 逻辑删除规则
所有业务表使用 `is_deleted=1` 标记删除，**不执行drop/delete物理删除**；查询业务数据必须带上 `is_deleted=0` 条件。

### 2. 计数字段说明
- `t_note`：`like_count`、`collect_count`、`comment_count`；
- `t_user`：`note_count`、`like_total`；
> 方案：优先Redis做实时计数，定时/事件回调更新mysql，避免高并发直接update数据库。

### 3. 图片存储
数据库只存**访问URL**，不存二进制图片；图片上传到对象存储，返回url存入 `t_note_image`。

### 4. 点赞、收藏去重
`t_user_like_note`、`t_user_collect_note` 设置联合唯一索引 `uk_user_note(user_id,note_id)`，数据库层面杜绝同一用户重复点赞/收藏。

### 5. 评论父子关系
`parent_id=0`：一级评论；`parent_id>0`：子回复；`reply_user_id`标记是回复哪一个用户。

### 6. 草稿设计
一个用户只保留**最新一份草稿**，使用唯一索引 `uk_user_id`，每次保存覆盖旧草稿。

## 关联关系总结
1. 用户(1) —— 笔记(N)：`t_note.user_id` 关联 `t_user.id`
2. 笔记(1) —— 笔记图片(N)：`t_note_image.note_id` 关联 `t_note.id`
3. 笔记(N) —— 话题(N)：通过中间表 `t_note_topic`
4. 笔记(1) —— 评论(N)：`t_comment.note_id`
5. 用户(N) —— 笔记(N)：点赞表、收藏表做关系映射
